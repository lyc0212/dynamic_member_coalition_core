
- 事后最优价值。

- 历史名义SWITCH的真实决策遗憾。

## 2.2 新增固定改派费用科研问题

对于每个已经执行的原始轨迹，计算：

```text
J_no_change(a) = J_original(a) + C_change(a)
```

其中 `C_change(a)` 是该动作对应实际轨迹在D60—D120期间发生的全部固定收费分配变化费用。

研究：

1. 移除固定费用后，原始价值优势是否仍然存在？
2. 固定费用是否改变动作排序、最优集合或名义SWITCH次优性结论？
3. 固定费用对实际决策遗憾产生了多大的直接会计影响？
4. 当前物理及任务执行后果是否已经能够体现联盟重构的代价？
5. 后续是否值得将无固定费用任务净收益作为主要研究评价目标，将分配变化次数作为独立指标？

不预设取消费用一定更好。

# G4-E：固定轨迹费用敏感性分析

## 31. 定义固定轨迹价值函数

对于具有完整费用及实际收费变化次数证据的动作：

```text
B_a = J_no_change(a)

N_a = N_change(a)

J(a; lambda) = B_a - lambda * N_a
```

其中：

```text
lambda >= 0
```

所有轨迹仍来自实际lambda_0=0.01执行。

不得重新调用Branch、WLS、Assignment或控制器。

参数变化仅发生在事后算术评价中。

---

## 32. 最低必要端点分析

至少计算：

```text
lambda = 0
lambda = 0.01
```

验证：

```text
J(a; 0) = J_no_change(a)

J(a; 0.01) ≈ J_original(a)
```

第二项允许冻结容差内的原始浮点累计差异。

分别报告ACTUAL三个动作的：

- 价值。
- 完整排序。
- 精确最优集合。
- 容差近似最优集合。
- 各动作遗憾。
- 名义SWITCH遗憾。

历史与全MODEL口径分别处理。

H1/H2/H3具有完整账本时，生成对应辅助端点评价。

不执行大规模参数网格扫描。

## 33. 两两动作临界费用

当：

```text
N_a != N_b
```

计算：

```text
lambda_star_ab = (B_a - B_b) / (N_a - N_b)
```

ACTUAL最多计算三个动作对：

```text
KEEP / SWITCH
KEEP / MEMBER_CHANGE
SWITCH / MEMBER_CHANGE
```

使用完整精度截距和整数变化次数。

优先保存有理数精确表示。

报告：

- 截距差。
- 变化次数差。
- 临界lambda精确值及显示值。
- 是否位于非负费用范围。
- 是否位于[0,0.01]。
- 临界点两侧的动作相对排序。
- 是否影响三动作事后最优集合。

如果两个动作N相同：

- 截距不相同：价值线平行，费用不会改变该动作对排序。
- 截距相同：价值线重合。

负临界费用仅作数学结果，不视为合理非负费用下的转换点。

大于0.01的临界点仅作固定轨迹外推参考，不代表已经验证的闭环最优费用。
