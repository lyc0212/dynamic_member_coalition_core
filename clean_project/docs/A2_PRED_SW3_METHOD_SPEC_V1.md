# A2-PRED-SW3 方法规范 V1

## 输入与共同假设库

输入是合法 D60 公开视图及固定 C6 团队。校验原公开字段、固定窗口和团队条件，读取 T1 公告中心 p、速度先验 v、设计半径 r、速度上限 V。首版只接受 v=(0,0)、有限 r>0 和 V>0，且目标以匀速运动。r 是实验设计尺度，V 是公告速度约束，两者均不提供概率。候选库由下列 5 个位置与 6 个速度做笛卡尔积，最多 30 项：

- 位置按 N、X+、X−、Y+、Y− 排序，分别为 p 和 p 加四个轴向 r/2 偏移。
- 速度按 N、E、NE、SE、北、南排序，分别为 (0,0) 以及长度 V/2 的五个方向。令 s=V/2，五个向量依次为 (s,0)、(s/√2,s/√2)、(s/√2,−s/√2)、(0,s)、(0,−s)。这些方向只是固定试探点。

候选须有有限数值、速度不超过 V、东向分量非负，且从 tick60 到含 tick100 的整段轨迹在公共方形域内，东边界 x=side 不得触及。匀速下检查起止两点即可。名义候选不合法则整族标为 BLOCKED。先按库序去重，留第一个；M1/M2 都使用同一剩余库。若合法独立候选少于 3，整族无法作主比较，报告不足，不复制候选、不替换为 K=2，也不因标签或预测结果另抽测试族。

## 三种选择方法

| 方法 | 选择规则 | 高保真模拟数 |
|---|---|---:|
| M0 | 仅名义 N/N | 1 |
| M1 | 依次取 N/N、X+/E、Y−/NE；若后两者不合法或重复，从库序取最早尚未选中的合法项 | 3 |
| M2 | 先取 N/N；从其余合法项依次取几何评分最高项和最低项，末项从尚未选中的项中选 | 3 |

M2 的低成本筛选只生成一条由 D60 冻结 belief 和原控制律得到的 C6 机器人轨迹。计算从 tick60 到 tick100 的固定控制参考，不消费假设 WLS，积分使用 0.05 秒及原限速。对每条候选运动，在每个端点计算：

```text
m_h(t) = geometry_tolerance - max_i || robot_i(t) - target_h(t) - role_offset_i ||
L_h = 按 m_h(t)>=0 的两端点规则得到的最长连续区间数
B_h = max_{a=60,...,79} min_{t=a,...,a+21} m_h(t)
score_h = (L_h, B_h)
```

按二元组字典序评分，高分对应更长的几何连续段，再以最有利的 21 区间最小余量细分。将 B 按十进制最接近的 1e-12、半偶舍入转为整数档用于排序；最高、最低并列都优先库序靠前。几何筛选没有 WLS，不做高保真 Q 判定；它可能错过反馈改变控制后的重要假设，也可能因选几何极端而使预测集合或时间包络过宽。评价协议专门记录这种失败。

## 规范化与隔离

原 D60 视图经公开 schema 及策略输入校验。稳定投影取 tick、end_tick、科学配置、按机器人序的位置与 Assignment、传感器声明、按目标 ID 排序的公告和 belief、公开服务历史和合法槽、固定角色以及首次公开时刻。禁止私有对象、运行身份、未来输入或结果字段；诊断和证明摘要如未被条件执行读取，不进入假设选择投影。类型校验后用 UTF-8、排序键、无空白 JSON 序列化，有限浮点用 binary64 十六进制字符串表示并把负零规范为正零，拒绝 NaN 和无穷。数组保持已声明顺序。用 SHA256 分别记录规范化公开输入、规范版本、合法候选库和有序选中列表。流标签可由这些公开摘要与方法内候选序号产生。选择本身不需要随机数或哈希择向。

三种方法均调用同一个 F1-only 条件执行接口。生成假设的接口仅接收公开投影，执行接口接收合法视图及所选公开假设。独立评估器在预测产物封存后才关联世界 ID 与标签。对同族所有物理世界逐字段核对有序假设和预测结果，拒绝根据私有身份、标签或未来 WLS 作出变化。
