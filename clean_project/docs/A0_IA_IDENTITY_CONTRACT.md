Public closed schemas are imported only as format definitions. The verifier separately implements digest recipes and canonical candidate enumeration. It does not invoke select, build_manifest, or physics.

IdentityMap requires explicit allowed path membership, namespace and decision scope, equal scientific objects and a bijection within that scope. It is a primitive, not a complete production mapping whitelist. No fields are globally ignored.

NOT YET COVERED: closed schemas for all candidate nested frame/event/estimator/quality objects; selection and committed action identity chain; complete actual STEP/fusion references; episode-index and audit links; SOURCE_PINS content verification; run-wide identity mapping contract. Consequently decision() intentionally returns IDENTITY_SUBSET_VALIDATED, never PASS.

Fixture tests use a checked historical single-target initial request, explicitly labelled FIXTURE. Digest expectation is independently checked with hashlib, not generated by the verifier. No multi-target episode is executed. SHA seals establish content consistency, not physical execution or trusted provenance.

### Remaining acceptance gap

This is not complete A0-Ia-2 acceptance: the existing prediction audit JSON contains only status/fusion_checks/prediction, without candidate/request identity or raw candidate file digest (worker candidate_gate). Current code binds it by expected path, PASS and fusion-count only. Decision and episode audits similarly have no authenticated source file digest. Thus file location is validated but a same-shaped substituted prediction audit is not fully detected. Closing this without worker changes requires independently reproducing the saved audit checks and comparing their full receipts; that is not yet implemented. Do not label A0-Ia-2 PASS.

Nested unknown-field closure and fixed mapping whitelist remain IA3. The batch boundary converts malformed structures to INVALID_EVIDENCE; generic fallback paths may identify the enclosing mode plus missing key rather than the exact deeply nested location. Required fusion fields have precise pointers. Complete nested-path validation remains unfinished.

No physical correctness, source execution authenticity, or multi-target scientific acceptance is claimed. SOURCE_PINS alone cannot prove execution.

## A0-Ia-2 receipt completion (supersedes preceding receipt-gap note)

`prediction_receipt()` now reconstructs the complete worker receipt using existing audit_fusion and audit_prediction functions on the admitted REQUEST, manifest descriptor and candidate result. Counter containers are serialized through JSON exactly as worker save() does; this conversion changes containers, not numerical values. `exact_tree()` enforces closed field sets, exact JSON types, list lengths and ordering, and float.hex equality (including signed zero). It reports escaped RFC6901 pointers for unknown/missing fields, wrong types and differing leaves.

Precise additional required-field checks cover fusion frame records, required result/context/registration/quality members, xy array shape/types and each sensor packet's required fields. Deferred IA3 scope remains all other nested format closure, fixed identity-mapping whitelist and generic deep schema diagnostics. Generic guarded() is only a final batch-crash safeguard, not claimed to provide exact field diagnostics for every unregistered nested object.

Receipt errors use /{mode}/D{d}/PREDICT/.../PREDICTION_AUDIT/{field...}. Recomputed-audit rejection reports the receipt's evidence context; explicitly checked radius failures include /evidence/sensing_results/{i}/result/quality/radius_proxy. This virtual evidence pointer is a report location, not an on-disk artifact path.

Negative matrix: whole C1 receipt replacing C0 -> fusion_checks length; same-shape foreign C1 radius -> exact indexed radius; modified internal fusion radius -> exact radius; changed prediction count -> prediction/counts/requests; unknown root -> added field; missing prediction -> prediction; string count -> count leaf; missing bearing -> frame/records/0/bearing; null record -> frame/records/0; changed audited radius -> evidence/.../radius_proxy. Assertions test INVALID_EVIDENCE and the exact expected pointer. Additional pointer-escaping/signed-zero tests preserve strictness.

This reuses the existing audit algorithms: it proves receipt/content consistency, not a second independent proof of audit correctness or authenticated historical execution. Byte-identical substituted receipts are indistinguishable without external provenance and are not required to be distinguished. No controller, candidate physical prediction or WLS estimator is invoked.

## A0-Ia-3 minimal mapping interface v1

Policy: scripts/gq_windows/a0_mapping.py, VERSION=a0_windows_identity_mapping_v1. RULES is a nested read-only mapping. IdentityMap.register no longer accepts allowed_paths. Register arguments include namespace, scope=(run_pair, decision, scientific_object), exact pointer, two identities, two strictly equal scientific objects, and keyword artifact. Only canonical nonnegative decimal array indices match '*'. Forward/reverse conflicts are rejected inside namespace/scope. Records retain both original identities and pointer; nothing is deleted or silently ignored.

| Artifact | Fixed pointer group | Namespace |
|---|---|---|
| operation | /operation/work_instance_id, /operation/physical_environment_id | work/environment |
| checkpoint | /checkpoint_id, /previous_checkpoint_id | checkpoint |
| request | /evaluation_request_id | request |
| manifest | /request_identity, /world_identity, /candidates/*/{candidate_id,evaluation_request_id,world_id} | request/world/candidate |

This table abbreviates brace alternatives for documentation only: code contains exact separate entries. No recursive suffix-name matching. No diagnostic numeric fields are exempted or tolerance-compared. Position, bearing, sigma, G/Q, clocks, event content, per-target returns, assignments and counts remain strict scientific data. Segment identities, payload hashes and any unlisted identity remain strict by default; if they differ, future Ib must reject rather than invent an exemption.

Ia-2 validators remain the internal-validity precondition. register() is a mapping primitive, not evidence admission: it cannot authenticate caller-supplied scientific objects or establish physical truth. Ib must first call mode_chain for each mode, use admitted artifact-specific scientific objects, then register only corresponding validated identities. Full artifact traversal and integration of these primitives are Ib/Ic tasks, not performed here. An unlisted required legitimate difference must be reported as an unsupported contract path for explicit review, never silently accepted.

Tests cover fixed immutable policy, valid indexed pointers, negative indices, unknown identities, nonmappable scientific fields, namespace mismatch, forward/reverse conflicts, scope separation, changed scientific objects and rejection of caller-supplied allowlists. Existing 42 tests retained, with old mapping calls migrated to the fixed API.
