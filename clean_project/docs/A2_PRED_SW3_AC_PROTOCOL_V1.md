# A2-PRED-SW3 A–C 研究协议 V1

目标是在相同的高保真模拟预算下，检验几何引导的假设选择能否提供更好的固定联盟连续服务预测。A 定义公开假设方法，B 冻结共同条件执行与结果契约，C 定义独立标签与比较方法。以 `153dad773c6112a9aff417b73ff6388b79e73bfe` 为科学基准。当前仅定稿，未实现或执行 SW3。

## 固定适用域

只纳入 tick60 新生且此前未分配的 T1、固定 U0/U1 q2 C6 角色、U2 空闲、二维匀速、零 bearing 扰动、窗口内传感器声明不变且无逃逸的场景。tick60–80 用冻结公开 belief，tick80 只进行一次合法 WLS 消费和控制更新，之后保持团队。自然完成可提前释放，tick100 是纳入判断的最后一个端点。研究对象是固定团队在该信息与控制制度下的完成情况。一般轨迹、任意联盟、任意故障和多次重规划留在本协议范围之外。

## B 的未来执行接口

`predict_f1(public_d60, public_hypothesis, horizon_tick=100) -> conditional_result`。从公开历史独立构建新 T1 服务段，在 tick60 形成首个左端点。21 个前缀端点使用原控制和正式模拟 Bridge；tick80 只消费当时合法可用的 MODEL 估计，接纳条件与 Q 独立。F1 延续服务段和进度，复用 tick80 左端点，从 tick81 建立新模拟流，按同一更新后的控制与原 G/Q 服务时钟运行。完成即停止该目标融合。MODEL 与正式 ACTUAL 通道仍隔离。

对每假设保存 `Y_H=(completed_by_H, completion_tick, observation_end_tick, terminal_status)`。完成时记录完成 tick 和同一观察终点，未完成记 `(false,null,100,ACTIVE_AT_H)`。异常或不合格输入单独标为无效。首版不将逃逸编码为成功预测状态。附最长连续服务、进度、剩余服务需求、合格端点及重置。

方法级结果保存 `predicted_completion_status_set`、去重排序的 `predicted_completion_ticks`、非空集合的最小最大包络（否则 null）、`noncompletion_possible`、所有逐假设结果及成本。若离散预测为 {91,97}，tick95 只落在包络中。未完成表示至 tick100 未完成。

现有 SW2 会同时执行 F0/F1，未来需要新增独立 F1-only 编排。首次实现先以既有名义和两例离线诊断检查 F1-only 与 SW2 的逐端点等价，包括观测队列顺序、接纳、belief、控制、G/Q、服务段、完成释放、原输入不变及正式执行接口零调用。离散字段严格相等，连续物理量沿用 SW2 绝对容差 1e-10，原内部 WLS 诊断差异单列。另验收 tick100 恰好完成及未完成的人工边界。

## 预算及阶段边界

设计上限按 21 个首窗端点加 20 个后续端点计算。现有 SW2 双分支每假设最多 61 次 WLS，拟定 F1-only 每假设最多 41 次，M0 最多 41 次，M1/M2 各最多 123 次。合法库的几何筛选最多 30×41 组候选端点、零 WLS，计入 M2 端到端 CPU 和墙钟。分别记录 K、实际高保真次数、WLS 上限、实调用数、完成提前终止节省及时间，M0 的低预算单列。在 11 族各预测一次且三方法不共用高保真结果的口径下，全部方法合计上限 3,157 次 WLS。以上为设计估算。

后续须先授权实现、等价测试及独立执行器，随后独立授权开发和测试数据生成及实验。开发集仅用于排查实现与场景形成，方法、λ、阈值和测试抽样表封存后才开启测试。M2 的预测质量和性能均待实测。只有科学方法及信息隔离成立才报告 METHOD_VALID。满足评价主判据才报告 PREDICTIVE_GAIN_OBSERVED；合法运行但不满足则记 NO_DEMONSTRATED_GAIN。无效标签、泄漏或不可比记 BLOCKED，保留证据。正式策略、DP 和收益均不改变。
