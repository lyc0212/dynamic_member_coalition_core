# A2-PRED-SW3 独立评价规范 V1

## 公开场景族与私有世界

以冻结 A2-VALUE-2 的物理配置、机器人初态、T0、服务要求、声明和控制规则为模板。族因子只改变合法预先公告的 T1 中心。以模板公告中心 (9.0,10.3) 为锚，横向偏移取 {−0.30, −0.10, +0.10, +0.30}，纵向取 {−0.25, 0, +0.25}，按横向后纵向递增编号，共 12 个不同候选族。T1 速度先验仍为零，r=0.5，V=0.8，其余公告字段原样保留。这些是研究设计尺度。两组已知 VALUE 轨迹仅用于接口等价测试，不参与开发或独立评价。

对编号 n 使用 UTF-8 文本 `SW3-V1|family|n` 的 SHA256 十六进制摘要升序排列，摘要并列按编号升序。前 3 族开发，后 8 族测试，第 12 族备用。仅在标签生成之前遇到公开 schema、运动适用域或固定物理准入失败时，可用备用族替换第一个不合格族，记录原编号、分组、规则与原因。仍不足则停止，禁止依据完成、难度、预测损失或标签替换。

每族按世界编号 0–3 构造四条不同私有匀速运动。候选尝试编号从 0 开始，每个世界最多 32 次。对分组、族编号 n、世界编号 w、尝试 a 和分量编号 j=0..3，分别取 UTF-8 `SW3-V1|world|split|n|w|a|j` 的 SHA256 前 8 字节，按大端无符号整数右移 12 位得到 52 位整数 z，置 u=(z+0.5)/2^52。四个 u 依次用于位置半径 r√u0、位置角 2πu1、速度长度 V√u2、速度角 π(u3−0.5)。位置为公告中心加极坐标偏移，速度在东向半盘内。使用首个符合原数据类型、固定运动、域约束、无逃逸且本族未重复的世界。两端点域检查同方法规范。抽样律是本次实验的人为覆盖设计，不能作为现实误差分布或算法的先验概率。任何耗尽、无效物理或 WLS 契约异常保留日志并报告，不能看结果后补样。

生成 D60 时，未来独立执行器使用原真实物理与观测机制，从合法初态到 tick60，按模板历史的前三个固定 C0 指令推进。T1 此前未出生，固定动作只用于形成可复核的共同历史。各私有世界独立形成 D60，核对正规公开视图和科学字段严格一致，不能手工拼接切口。非关键运行身份按已登记契约核查。同族只生成一份封存预测，映射到四个独立世界标签。需有独立入口与授权才能生成数据，本轮没有生成。

## 独立标签与盲评

未来真实参照调用原物理执行器、正式测量、WLS、实际观测队列及原服务时钟，从各自 D60 强制提交 C6，在 tick80 合法冻结一次后继续保持原团队，到完成或含 tick100 停止。固定指令是研究干预，记录为固定联盟参照。T0 在这一段不分配，U2 空闲。不调用被测 F1-only、假设库或 M2 来生成标签。所谓真实标签指项目内独立物理仿真结果。

严格核对固定输入、队列因果时序、服务、反馈、释放和标签。预测器仅接收 D60，实际运动与未来观测只进标签执行器。先封存方法、依赖、试验抽样清单和预测，再由评估器关联独立标签。测试同族所有四世界的假设与预测一致，记录计划外退出、无效标签和每次重抽。正式比较若缺任何合法测试族或世界，标为 BLOCKED 并保留其他结果。

## 主指标与成功判据

世界真实类 y 为 tick100 前含该端点完成与否，预测集合 S 必须非空。主损失 L = I(y∉S) + λ I(|S|=2)，主 λ 固定 **0.25**。错误排除真实结局的代价为 1，报告两种结局的代价为其四分之一。λ 不在开发集拟合。敏感性值事先固定为 **0、0.10、0.50**，另报但不改变主判定。

以每族四世界平均损失为一个族结果。每族求 D = L_M1 − L_M2，再对八个测试族等权平均。预先规定观察到预测改善需同时满足：

1. 平均 D ≥ 0.05。
2. 至少 5 个测试族 D>0，平局不计改善。
3. M2 的全体类别覆盖率至少等于 M1。

该阈值是事先的探索性实用门槛。只作 M2 对 M1 的同预算主要比较，M0 为低预算基线并列报告。输出每族和每世界损失、D、总体结果与全部敏感性。方法有效而主规则未同时成立，报告 NO_DEMONSTRATED_GAIN。不得按单个次指标翻转主结论。

## 次指标与报告口径

- 在全部有效世界报告真实类覆盖率及三类集合输出比例。单列两类混合集合比例相对 M1 的变化，检验极端筛选是否增加模糊性。
- 在真实完成的世界报告离散 tick 命中率、包络覆盖率。空预测时间集合一律记未命中，单列其比例。对非空预测时间集合报告宽度及中位 tick 的绝对误差，中位取排序后靠下的中央元素。另报到最近离散 tick 的距离作为集合诊断，明确其是事后最近匹配。误差统计给出共同有预测时的配对结果及分母。
- 风险提示定义为名义 M0 预测完成且相应多假设集合包含未完成。对 M0 误判为完成的世界报告提示率，对 M0 正确预测完成的世界报告误报率。名义误判为未完成另报多假设是否包含完成。分母为零记 N/A。
- 报告 K、高保真调用、WLS 预算和实调用、包含筛选的端到端 CPU 和墙钟。测试八族各方法计算一次，避免把族内四标签计作四份不同预测。

每私有世界提供一条真实标签，族内四个标签共享预测和初始公开信息。K 个假设不增加独立样本。主汇总保留 8 个测试族分组，共 32 世界，开发 3 族共 12 世界。该规模用于观察和诊断，不作强泛化或统计显著性主张。保留全部合法负结果、平局及覆盖代价；最终报告分别给出 METHOD_VALID 与预测收益判定。
